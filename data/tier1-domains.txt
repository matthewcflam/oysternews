# Tier-1 outlets: wire services, papers of record, and the independent /
# investigative outlets that carry that role in their region.
# Matched against GDELT's SourceCommonName, which is a bare domain, lowercased,
# EXACT — no substring or suffix matching. theguardian.com does not match
# warringtonguardian.co.uk, and dawn.com does not match dawnofthedawg.com; both
# of those are real domains in the sample feed.
#
# THIS LIST IS LOAD-BEARING, not descriptive. HANDOFF.md §2.5: a story with a
# tier-1 article in the last 48 hours outranks every non-tier-1 story in its
# tile, whatever their salience. tier1Fresh is the FIRST key of compareGroups,
# so precedence is absolute, not weighted. The list was originally built to
# MEASURE coverage for the blindspot feature; that feature was killed by
# measurement (tier-1 was 1.05% of the stream, so the flag fired on 98.6% of
# stories) and the same domains now GRANT precedence instead. Editing this file
# changes what is on the map.
#
# --- 2026-08-13 expansion -------------------------------------------------
# Expanded from 28 domains to the regional list below. The old list was 91%
# US/UK outlets (FINDINGS.md §11) — a "tier-1 outranks everything" rule built on
# it means a US or UK byline beats local reporting anywhere on Earth. The
# expansion is the fix: every region gets outlets that can win their own tiles.
#
# The 28 originals are all KEPT, not replaced. cnn/bbc/newsweek/latimes are ~60%
# of the tier-1 records that actually appear in the feed; dropping the arguable
# ones would gut a signal this expansion is trying to thicken, not thin.
#
# The cost is dilution: precedence is only meaningful while it is scarce. As the
# tier-1 share of any tile's candidates rises, the first comparator key stops
# separating and salience silently takes over — the same failure that killed the
# blindspot flag, in the other direction. Measured on the Phase 2.5 maturity
# sample (12 bundles, 5,252 groups, 1,447 distinct domains):
#
#   article-level tier-1   1.04%  ->  3.62%
#   group-level tier-1     1.35%  ->  4.74%   (71 groups -> 249)
#
# Still scarce, so first-key precedence still separates. Re-measure after
# Phase 3; if group-level clears ~15%, the flat override should become a
# salience bonus instead.
#
# Only 34 of these 128 domains appear in that sample at all, and thehindu.com
# alone is 82 of the 250 tier-1 article slots — a third of the whole signal,
# from one high-volume outlet that blocklist.txt already calls out as sitting
# at the top of the domain histogram. Watch for Indian city tiles going
# permanently to The Hindu. Absent domains cost nothing: if GDELT ever starts
# crawling Reuters or Le Monde at volume, they just work.
#
# Domains carrying a known funding or alignment caveat are marked. The caveat is
# NOT a reason to exclude — it is a reason for a future reader to know why the
# entry is here before editing it.
